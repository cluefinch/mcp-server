# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Before opening an issue, check the README, existing issues, and the documented project boundaries.

For usage questions, include the Cluefinch version, Python version, platform, MCP client, and a sanitized description of the SearXNG setup. Do not post secrets, authentication material, private URLs, captures, or sensitive retrieved content.

Security vulnerabilities should not be reported in a public issue. Follow `SECURITY.md` and use GitHub private vulnerability reporting or security@cluefinch.com.

Cluefinch MCP is local-first infrastructure. Support does not include debugging unrelated MCP clients, upstream search engines, arbitrary SearXNG deployments, paywall/captcha bypass, JavaScript rendering, or hosted service operations unless the issue demonstrates a Cluefinch defect.
